# 🏺 ZEGEN IVOIRE

Plateforme e-commerce pour la vente d'attieke authentique en Côte d'Ivoire.

## 📋 Fonctionnalités

✅ **Catalogue produits** - 7 types d'attieke avec images  
✅ **Panier d'achat** - Gestion des quantités  
✅ **Paiement flexible** - Wave, Orange Money, Cash on Delivery  
✅ **26 zones de livraison** - Frais calculés par quartier  
✅ **GPS/Géolocalisation** - Capture automatique des coordonnées  
✅ **Historique commandes** - Suivi client complet  
✅ **Tracker de livraison** - 4 étapes visuelles  
✅ **Téléchargement factures** - Format HTML  
✅ **Admin Panel** - Gestion des commandes et produits  

## 🚀 Déploiement sur Netlify

### Étape 1 : Créer un compte GitHub
1. Aller sur [github.com](https://github.com)
2. S'inscrire gratuitement
3. Créer un nouveau repository: `zegen-ivoire`

### Étape 2 : Pousser les fichiers
```bash
# Dans le terminal, dans le dossier Desktop
git init
git add .
git commit -m "Initial ZEGEN IVOIRE deployment"
git branch -M main
git remote add origin https://github.com/VOTRE_USERNAME/zegen-ivoire.git
git push -u origin main
```

### Étape 3 : Déployer sur Netlify
1. Aller sur [netlify.com](https://netlify.com)
2. Cliquer "Sign up" → Choisir "GitHub"
3. Autoriser Netlify
4. Cliquer "New site from Git"
5. Sélectionner le repository `zegen-ivoire`
6. Cliquer "Deploy site"

**✅ Votre site sera en ligne en 2-3 minutes !**
